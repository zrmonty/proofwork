# Use Proofwork

Inspect, decide, edit, verify and finish authorized outcomes. Resolve routine choices; work around missing facts. Respect read-only intent, authority, established style and public contracts.
Preserve caller data and nested aliases; name mutable owners.

Run `node <plugin-root>/scripts/proofwork.mjs route --explain --repo <target-repo> --task <text> --files <paths>`.
Read procedure.path, selected skills, principleReferences and workflow.beforeWork; load other workflow phases when reached. Record a principle only when it changes a decision in internal decision/evidence notes; expose it on inspection. Correct intent routing; preserve risk floors on overrides.

Apply teamPolicy rules and required evidence; read [team policy](../../contracts/team-policy.md) when configured. Record IDs, disposition and evidence/gaps in the report. On resume reroute the actual next action and compare policy digest; recheck affected decisions after policy changes. Policy cannot override the user, host limits or read-only intent.

- **light:** [light procedure](references/light.md); bounded change and check, no ledger/team.
- **standard:** relevant guidance; conditional functional extraction for qualifying state/retry/concurrency work;
  TDD for executable behavior. Unresolved products brainstorm; structure uses architecture/language fit.
- **full:** [coordination](references/full-workflow.md), [runtime](../../adapters/runtime.md),
  [goal rules](../../adapters/goal.md) and [tools](../../scripts/README.md); ownership, checkpoints and evidence.

Read [model patterns](references/model-patterns.md) for consequential alternatives/review; resolve configured roles through pw-setup. Settle integrated findings. Before authorized commits read commit-features; formatting requires opt-in. Use clear-voice for documentation/comments/reports and evidence-surface for actual checks, gaps and operator actions. Routine work skips setup and keeps reports short.

Read [handoffs](references/handoffs.md) for material stage changes or interacting skills; on resume load continuation.references first. Light recovery stays light. Keep one objective, coordinator and finding list.

Full-tier and Harden-and-Finish deliveries link one [systems outcome](../../contracts/systems-outcome.md), including incomplete work. Reuse evidence; scoped success is not production readiness.
