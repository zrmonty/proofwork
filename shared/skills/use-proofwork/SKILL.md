# Use Proofwork

Inspect, decide, edit, verify and finish authorized outcomes. Resolve routine choices; work around missing facts. Respect read-only intent, authority, established style and public contracts.
Preserve caller data and nested aliases; name mutable owners.

Run `node <plugin-root>/scripts/proofwork.mjs route --explain --task <text> --files <paths>`.
Read procedure.path, selected skills, principleReferences and workflow.beforeWork; load other workflow phases when reached. Record a principle only when it changes a decision in internal decision/evidence notes; expose it on inspection. Correct intent routing; preserve risk floors on overrides.

- **light:** [light procedure](references/light.md); bounded change and check, no ledger/team.
- **standard:** relevant guidance; conditional functional extraction for qualifying state/retry/concurrency work;
  TDD for executable behavior. Unresolved products brainstorm; structure uses architecture/language fit.
- **full:** [coordination](references/full-workflow.md), [runtime](../../adapters/runtime.md),
  [goal rules](../../adapters/goal.md) and [tools](../../scripts/README.md); ownership, checkpoints and evidence.

Read [model patterns](references/model-patterns.md) for consequential alternatives or independent review; resolve
configured roles through pw-setup. Settle material findings on the integrated artifact. Before authorized commits,
read commit-features; enforcement requires opt-in. Apply clear-voice while writing docs/comments and every final
report. Skip setup for routine work. Explain before/after, checks, uncertainty and operator actions without technique names. Use evidence-surface to connect outcomes to actual checks, identities and gaps; routine reports stay short.

Read [handoffs](references/handoffs.md) for stage changes, interacting skills or resume; load continuation.references on resume. Keep one objective, coordinator and finding list.
