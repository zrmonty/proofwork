# One task, successive stages

Use when accepted intent moves into another stage, a correction affects several skills or a run is resumed. Keep one objective, current brief, authority boundary and evidence history. The router recommends the current subtask; it does not own conversational acceptance or authorize an external effect.

## Start with the outcome

Inspect repository instructions, existing work and the requested journey. Resolve routine choices yourself. New unresolved intent uses Shape Intent; an accepted brief skips renewed brainstorming. Clarify Path returns understanding without edits. A small change can finish directly with a real check and one sentence of evidence. Setup is conditional on a missing relevant capability, not a mandatory questionnaire.

Referencing another skill means loading its applicable contract into this task. It does not restart the root, create another run, launch another panel or dispatch automatically. Reuse existing checks, artifacts, findings and assignments when they answer the same question. A changed artifact requires rechecking affected evidence.

## Carry acceptance across the boundary

After a material transition, reroute only the next actionable subtask with actual affected files. Keep accepted product choices and adequate incumbent technology. Checkpoint its existing playbook stage, selected skills and concrete nextAction in an active full run; do not create run state just to record light work. Never checkpoint Resume Work's placeholder stage before inspecting the bound run and identifying its actual next action.

New user constraints update dependent decisions, assignments and checks. Preserve unaffected work; do not replay discovery or finish against superseded criteria. A pending answer blocks only work requiring it. Silence grants no consequential authority.

## Preserve a single coordinator

The coordinator executes bounded work directly. Worker-mode belongs to explicitly assigned workers, which receive their ownership and evidence contract before writing. Load model patterns only when alternatives or independent review justify the cost. Missing multi-model or fresh-context support leaves that independence unverified; continue useful authorized work without inventing access.

The native host owns goals and continuation. Resume reconciles actual checkout, worker status and uncertain external effects before retrying; a saved identifier is not liveness. Full-run preflight is read-only. Honest incomplete delivery preserves the next action and gaps rather than claiming readiness from a passed build.
