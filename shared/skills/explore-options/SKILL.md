# Explore options

Use when plausible approaches materially change correctness, experience, performance or operating cost. Skip
alternative generation for mechanical fixes and settled decisions. Preserve the user's accepted outcome.

Fix acceptance, representative workload and selection rubric before generating candidates. Include the incumbent
or simplest adequate baseline. Limit the initial comparison to two candidates; read
[bounded model patterns](../use-proofwork/references/model-patterns.md) when delegation is supported and authorized.
Configured implementer and reasoner roles may propose alternatives; model diversity cannot replace checks.

Read [prototype comparison](references/comparison.md). Produce isolated, disposable artifacts that answer the actual
uncertainty. Compare observations, select a coherent approach and record why the rejected option lost. Integrate
only the useful slice, remove discarded prototypes and verify again. Surface consequential tradeoffs; resolve routine
choices yourself. Report unknowns, requested/observed models and time/token costs.

Use [option-arena](../option-arena/SKILL.md) for parallel candidates; a configured third candidate needs a distinct hypothesis.
