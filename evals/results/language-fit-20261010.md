# Language-fit verification

Date: 2026-10-10. Version: 0.15.0.

## Delivered capability

Originally authored language-fit evaluates languages, runtimes and frameworks across systems, scripting/automation and fullstack/presentation responsibilities. It challenges habitual TypeScript/React choices without mandating Rust/Python/Vue. Critical native work seriously compares Rust, C++ and C with applicable alternatives. Responsibility categories do not require separate services or multiple languages. Recommendations cover candidate fit, actual workloads, operating owners, boundary costs, primary documentation and evidence gaps; choice-only work does not authorize scaffolding, migration or deployment.

Two conditional references cover critical-path/FFI/mixed-language decisions and frontend/rendering/backend/automation choices. Official Vue, React, Rust FFI, Python extension/embedding and C++ guideline pages were fetched for applicable constraints; no external skill prose was copied. Architecture-fit and the root load language-fit for relevant undecided technology. Architecture playbook, specifications, command README and reference/authoring guides map the capability. Both packages contain the 23 canonical skills.
