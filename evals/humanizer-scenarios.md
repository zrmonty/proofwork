# Humanizer editorial scenarios

Status: authored acceptance prompts for 0.37.0, not executed reader studies or rendered application tests.
Evaluate against supplied facts and context, not exact wording matches. Preserve clear existing copy.

## Specificity without invented benefits

Prompt: Rewrite "Unlock a seamless reporting experience and harness powerful insights." The product exports
invoices as CSV for a chosen date range. No analytics or email delivery exists.

Pass when the action, format and useful constraint replace unsupported praise. Do not invent insights,
notifications or popularity. A clear label can suffice if the surrounding screen already explains the facts.

## A formal voice remains recognizable

Prompt: Simplify an owner's invitation-permission notice in a formal business product. Owner is the canonical
role name. Existing labels use Invite members and Workspace.

Pass when grammar becomes familiar and direct without slang, renamed roles, forced contractions or weakened
permissions. Preserve domain terms; varying Invite, Add and Enroll merely to avoid repetition fails.

## Empathy with known and unknown facts

Prompt: Rewrite "Oops! We understand how frustrating this is. Don't worry, nothing was lost." The save failed;
retained input has not been verified. A second fixture confirms retention and safe retry.

Pass when the first case avoids promises about preserved work; the second may provide that useful reassurance.
Both state the actual outcome and supported next step without guessing feelings or claiming a team is fixing it.

## Preserve real structure

Prompt: Simplify repeated title/subtitle/card introductions on settings. Shared navigation, required links and
a long help article's meaningful sections are outside the repetition problem. A frequency control has three options.

Pass when redundant orientation is removed while useful headings, landmarks and Daily/Weekly/Monthly choices
remain. A no-header/no-footer rule, list ban or deletion of shared content outside scope fails.

## Dynamic values and uncertain effects

Prompt: Rewrite a mixed-result invitation summary. The message uses named count variables and existing plural
rules. Some invitations are queued, some refused and some unknown; membership has not been accepted.

Pass when the summary preserves distinct outcomes, full-message interpolation, object identity and safe
recovery. No blanket success, accepted-member claim, invented translation or private diagnostic disclosure.
Implemented strings require their own resource, rendering and interaction checks.

## Necessary detail survives a warmer tone

Prompt: Make a file-retention explanation friendlier. Supplied facts are 30-day retention and owner-only early
deletion. Approved consent wording is present beside it. The user requests findings only.

Pass when the proposal retains both facts and approved consent meaning, with no repository edits. More
comforting but imprecise "keep files as long as you need" fails. Report missing render/language checks.

## No cosmetic detector chase

Prompt: Humanize a clear paragraph containing a semicolon, an em dash and three genuine setup steps.

Pass when a sound passage can remain intact. Any edit needs a comprehension, tone or meaning reason. Do not
claim human authorship, optimize to a detector score, add errors or cycle through synonyms without a defect.

## Use literary flow without literary interface copy

Prompt: Improve a two-sentence upload explanation using one novel-flow example. The product requires a
header row, rejects files without it and supports uploading again after correction. A separate request
changes only the Upload button label.

Pass when the explanation connects the supplied cause to the supported next step and keeps its referent
clear. Preserve state, register and terminology; do not borrow quoted language, invent memories, delay
the action with scene-setting or add unnecessary paragraphs to the standalone label. The source example
is a conditional reference, not a mandatory reading exercise for every control.
