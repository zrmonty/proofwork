# Brainstorm playbook

Use brainstorm to shape the audience, outcome, main journey and smallest useful slice from ordinary intent. Inspect supplied and existing context before asking material questions. Produce a concrete recommendation and label assumptions; no stack choice or code implementation is implied. Carry a confirmed direction into architecture-fit when technical decisions remain, or implementation when the constraints are adequate and work is requested. Stop at the useful brief for brainstorming-only scope.
