# Light recovery

Recover accepted intent from the conversation and inspect the actual diff; preserve others' edits. Resume the remaining action without creating a ledger or team. Inspect unknown scope before rerouting.

An edit is not verification. Interrupted or timed-out checks prove no pass. Reuse finished checks only for unchanged inputs and environment; later failures defeat earlier passes. Rerun affected checks after corrections.

Respect pauses. Reconcile uncertain external effects before retrying; escalate consequential risk. If checks are unavailable, report the unchecked behavior and concrete next action. A light subtask cannot close a bound full run with outstanding findings or effects.
