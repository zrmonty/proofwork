# Resume Work

Inspect the explicitly bound run, checkpoint, checkout identity, live owners and actual external state. Reconcile interrupted effects before retrying. Reuse evidence only for unchanged dependencies; never select the newest unrelated run. Reassess the current stage and continue its next verifiable unit. Do not invent a checkpoint when none exists.

Use continuation.references from the route: light work uses [light recovery](../skills/use-proofwork/references/light-recovery.md); other work uses [run recovery](../skills/use-proofwork/references/recovery.md). With no run, inspect the conversation and current diff; do not create a ledger to resume a small edit. Reroute the actual next action before checkpointing a stage. Unknown scope needs inspection, not automatic full coordination.
