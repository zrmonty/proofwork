# Clear Voice

Make actions and limits clear. Replace vague intensifiers, empty jargon and forced triples with useful specifics;
keep stylistic choices that serve readers. Preserve exact strings, quantities, safety meaning and provenance.
Distinguish requests, observations, inferences and missing checks. Never polish uncertainty into success.

Match the audience's vocabulary; do not impose a universal style blacklist.
