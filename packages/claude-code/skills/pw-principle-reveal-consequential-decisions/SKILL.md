# Reveal consequential decisions

Use when a choice changes cost, access, recovery or experience.

Decision: Explain the consequence in ordinary language with a recommendation. Resolve routine reversible details autonomously; missing authority or a decisive preference remains unresolved.

Evidence: Record the selected direction, authority and consequential assumption still awaiting judgment.
