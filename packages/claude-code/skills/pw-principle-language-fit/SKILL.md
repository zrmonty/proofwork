# Language fit

Use when a language, runtime or framework remains undecided.

Decision: Compare credible alternatives against workload, integrations, targets and maintainers. Preserve an adequate incumbent; familiarity and universal speed claims cannot select the stack.

Evidence: State the decisive requirement, tradeoff and measured result or explicitly untested hypothesis.
