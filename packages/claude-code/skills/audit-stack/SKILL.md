# Audit stack

Coordinate requested lenses through [use-proofwork](../use-proofwork/SKILL.md); do not redispatch the aggregate recursively or create a second scheduler. Default to supported local repairs, respecting report-only instructions and actual authority for publication, deployments, credentials or public retirement.

Establish scope, current artifact identity and preserved behavior once. Select [security](../security-hardening/SKILL.md), [dead code](../dead-code-audit/SKILL.md), [duplication](../dry-audit/SKILL.md), [performance](../performance-increase/SKILL.md), [coverage](../tdd-95/SKILL.md), [architecture](../architecture-fit/SKILL.md) and [structural review](../thermo-nuclear-code-quality-review/SKILL.md) from their own contracts. Apply language, UI/copy and release guidance only where the actual surface warrants it.

Maintain one prioritized finding ledger and explicit per-lens status: assessed, not applicable with reason, or unverified with missing evidence. Merge common causes while retaining each lens's proof obligations. Reading instructions is not assessment.

Use [repair interactions](references/repair-interactions.md) for conflicts and dependencies. Establish deadness before extraction; repair authority before optimizing; give modifying workers disjoint ownership. Integrate by dependency and recheck evidence invalidated by later edits.

Deliver audited identity/surface, prioritized findings, actual repairs, retained decisions, integrated checks and unresolved actions. The owning lenses define their gates; do not restate or waive them here. Scanner silence, source subtraction or execution coverage cannot establish comprehensive correctness, security or readiness. Keep raw secret-bearing evidence private.
