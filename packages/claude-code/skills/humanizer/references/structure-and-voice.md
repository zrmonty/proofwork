# Structure and voice

Read this when a page sounds formulaic or its structure overwhelms the content. Work from the actual audience and screen, not a universal style checklist.

## Find the repeated template

Look across the page and adjacent screens for layers that repeat the same job: an eyebrow naming the page, a headline repeating it, a subtitle promising value, a paragraph repeating the subtitle, and a card title introducing the same action again. Keep the element that gives useful orientation and the facts needed for the decision. Remove the rest or combine its unique information with the appropriate sentence.

A possible settings edit:

```text
Before
YOUR EXPERIENCE
Take control of your notification journey
Stay effortlessly connected with what matters most.
Notification preferences
Customize how you receive notifications.
Email updates [toggle]

After
Notifications
Email updates [toggle]
Get an email when someone replies to your post.
```

This example assumes the toggle really controls reply emails. If it controls several events, describe those events or retain a suitable broader label. A shorter sentence that changes the promise is not an improvement.

## Distinguish content headings from page chrome

| Element | Keep it when | Simplify it when |
| --- | --- | --- |
| Page title | It identifies the destination and supports orientation | Multiple title layers say the same thing |
| Section heading | Readers need to distinguish meaningful topics or scan a long page | A tiny group already has a clear label and no separate topic |
| Site header | People need navigation, identity or account access | A second navigation bar duplicates the first without a useful role |
| Footer | Legal links, credits, publication navigation or relevant support belong there | Every in-app screen inherits a large promotional sitemap and repeated action |
| Closing action | It follows a meaningful decision or long reading flow | The same action is already obvious and repeated for decoration |

Do not remove landmarks or visually hide meaningful text solely to make the page look sparse. Preserve reading order and semantic nesting. When a framework's layout owns the common header/footer, change that shared layout only if its consumers are within scope; otherwise make the local content fit it and report the shared issue.

A publication archive can need a masthead, topical navigation and copyright. An editor modal can need only its title, inputs and save/cancel controls. A long help article benefits from descriptive sections. The skill does not impose a maximum number of headings or outlaw ordinary layouts.

## Use a voice with evidence

Derive the voice from representative existing copy that fits the product, the person's situation and supplied brand constraints. A useful short note might say:

```text
Audience: people organizing a neighborhood reading group.
Vocabulary: event, member, RSVP; do not alternate attendee and customer.
Relationship: helpful and direct, warm in invitations, calm in errors.
Action: Create event.
Help: Add a place or a video-call link.
Error: The event wasn't saved. Your details are still here; try again.
```

The error example is valid only if the implementation retained the details and retry is safe. Supplied voice examples establish style, not evidence for system behavior. An established formal service can stay formal while becoming clearer.

## Diagnose the sentence, not a blacklist

| Pattern | Why it often fails | Better question |
| --- | --- | --- |
| Generic promise such as seamless experience | It gives no decision-relevant fact | What specifically becomes possible or easier? |
| Stock invitation such as dive into | It delays the subject | Can the sentence start with the content or action? |
| Repeated three-part benefit list | It creates a cadence unrelated to actual information | Which benefits are distinct, supported and needed here? |
| Dramatic contrast in every section | It substitutes a rhetorical formula for explanation | Can we state the outcome and reason directly? |
| Excessive enthusiasm | It ignores the seriousness or repetition of the moment | How would a considerate colleague describe this state? |
| Artificial casualness | It can exclude readers or reduce confidence | Which ordinary words preserve the intended relationship? |

These are diagnostic prompts. A real three-option choice belongs in a list. A genuinely playful product can use playful copy. Do not remove a necessary term, technical distinction or brand expression merely because it appears in generic writing elsewhere.

Read revised text in the order a person encounters it. Keep deliberate repetition for stable actions and important consequences; remove decorative repetition. Prefer a specific, useful line over a performance of friendliness.
