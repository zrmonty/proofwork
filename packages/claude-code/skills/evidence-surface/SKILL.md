# Evidence Surface

Connect consequential claims to rerunnable procedures, environment, artifact identity, actual results and gaps.
Label manual, claimed and directly observed evidence; state unknowns. Preserve failures and interruptions.
Never invent checks or findings. Redact private information. Tiny edits can use one sentence without a ledger.

Read actual output before claiming success; keep sensitive raw evidence local.
