# Option arena

Use when competing implementations can answer a consequential uncertainty more cheaply than argument. Skip
mechanical edits and accepted choices. Read [explore options](../explore-options/SKILL.md) for the comparison contract
and [model patterns](../use-proofwork/references/model-patterns.md) for supported dispatch and ownership.

Freeze the brief, acceptance checks, incumbent baseline, workload, selection rubric and resource ceiling before
generation. Start with two candidates. A configured third candidate needs a distinct hypothesis worth its additional
cost; respect maxCandidates, maxParallel and actual host authority. Different model labels do not establish independence.

Give each candidate the same brief and starting artifact in fresh isolated workspaces. Disclose dependencies equally;
keep candidate verdicts separate until comparison. Record requested and observed model/effort, elapsed time and
available token/cost observations; unavailable accounting stays unknown. Stop scheduling when the budget is exhausted.

Eliminate contract failures before scoring measured benefit and operating burden. Choose a coherent candidate or a
specific useful slice. Grafting strengths produces a new artifact: integrate under one owner, then run fresh acceptance
and regression checks on that combination. Preserve unrelated changes and reconcile unfinished worker effects.

Return the comparison, selected artifact identity, rejected hypotheses, integrated checks, costs and remaining gaps.
