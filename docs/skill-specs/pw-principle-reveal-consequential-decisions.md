# Specification: pw-principle-reveal-consequential-decisions

Citable principle: `reveal-consequential-decisions`. Trigger: Use when a choice changes cost, access, recovery or experience.

Decision contract: Explain the consequence in ordinary language with a recommendation. Resolve routine reversible details autonomously; missing authority or a decisive preference remains unresolved.

Acceptance evidence: Record the selected direction, authority and consequential assumption still awaiting judgment.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
