# Specification: pw-principle-prove-the-journey

Citable principle: `prove-the-journey`. Trigger: Use when a change spans user actions or surfaces.

Decision contract: Exercise the combined flow and consequential failure state. A component test, build or screenshot cannot establish behavior it never reaches.

Acceptance evidence: Record the actual interaction, integrated artifact and remaining access limits.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
