# Specification: pw-principle-reproduce-before-fix

Citable principle: `reproduce-before-fix`. Trigger: Use when correcting a reported or observed defect.

Decision contract: Obtain a distinguishing failure before changing the rule. If execution is unavailable, keep the diagnosis provisional rather than inventing a red test.

Acceptance evidence: Show the original failure and repaired behavior under comparable conditions.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
