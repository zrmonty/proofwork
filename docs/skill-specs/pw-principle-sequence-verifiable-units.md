# Specification: pw-principle-sequence-verifiable-units

Citable principle: `sequence-verifiable-units`. Trigger: Use when work has dependent changes or shared ownership.

Decision contract: Settle the prerequisite contract, then integrate cohesive units with independent acceptance. Separate paths do not remove semantic dependencies or authorize overlapping writes.

Acceptance evidence: Identify each accepted unit and revalidate checks invalidated by later integration.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
