# Specification: measure-loop

Trigger: a measured bottleneck warrants successive attributable experiments. Inputs: representative workload, baseline,
artifact, environment, variability, acceptance limits and budget. Output: retained changes, comparable before/after
measurements, uncertainty, checked regressions and rejected hypotheses. Delegate benchmark mechanics to performance-increase.

Acceptance: one hypothesis/change is assessed per iteration; unavailable measurements remain gaps; acceptance requires
observed useful improvement and correctness; rejected work removes only owned edits; stateful effects reconcile before
retry; shared paths isolate experiments; combined accepted changes receive fresh checks; noise or exhausted budget stops
the loop without fabricated success.
