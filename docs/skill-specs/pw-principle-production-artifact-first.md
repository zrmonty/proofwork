# Specification: pw-principle-production-artifact-first

Citable principle: `production-artifact-first`. Trigger: Use when preparing release, hosting or deployment.

Decision contract: Build and inspect the deliverable users will run under its real startup/configuration contract. Development success does not prove image contents, secret handling or production readiness.

Acceptance evidence: Record artifact identity, startup/health observations and unavailable deployment checks.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
