# Specification: pw-principle-intent-stays-with-user

Citable principle: `intent-stays-with-user`. Trigger: Use when interpreting an ambiguous request or later correction.

Decision contract: Translate intent into observable outcomes without substituting a preferred product or stack. Preserve accepted constraints and useful work unless the correction invalidates them.

Acceptance evidence: Tie the delivered slice to current intent and identify any deferred scope.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
