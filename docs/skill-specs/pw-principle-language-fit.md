# Specification: pw-principle-language-fit

Citable principle: `language-fit`. Trigger: Use when a language, runtime or framework remains undecided.

Decision contract: Compare credible alternatives against workload, integrations, targets and maintainers. Preserve an adequate incumbent; familiarity and universal speed claims cannot select the stack.

Acceptance evidence: State the decisive requirement, tradeoff and measured result or explicitly untested hypothesis.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
