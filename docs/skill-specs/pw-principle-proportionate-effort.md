# Specification: pw-principle-proportionate-effort

Citable principle: `proportionate-effort`. Trigger: Use when selecting investigation, delegation or checks.

Decision contract: Spend effort where failure consequences or unresolved evidence warrant it. A rename should not inherit a migration ceremony; a risky write cannot borrow rename-level verification.

Acceptance evidence: Identify the decisive checks and the uncertainty they addressed.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
