# Specification: procedure-draft

Trigger: novel repeatable work has no adequate existing workflow. Inputs: outcome, scope, prerequisites, operator,
authority, effects and acceptance. Output: reviewable versioned steps, observations, checks, stop conditions, recovery
ownership and explicitly untested prerequisites. Existing workflows take precedence; new-project requests do not trigger
procedure creation automatically.

Acceptance: each step has an observable check and stopping rule; uncertain writes reconcile before retry; recovery
promises specify state limits; safe rehearsal distinguishes executed evidence from assumptions; procedures do not expand
external authority; delegation has ownership; future execution is never reported as already complete.
