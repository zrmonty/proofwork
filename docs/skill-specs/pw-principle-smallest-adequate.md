# Specification: pw-principle-smallest-adequate

Citable principle: `smallest-adequate`. Trigger: Use when several implementations satisfy the request.

Decision contract: Compare real acceptance and operating needs. Prefer the smallest adequate mechanism; retain complexity that protects an actual contract.

Acceptance evidence: Show the satisfied outcome and any requirement that justified extra machinery.

Apply only to the actual assignment. The principle adds a decision lens, not a second workflow or authorization. Packaging validation establishes discoverability, not agent compliance.
