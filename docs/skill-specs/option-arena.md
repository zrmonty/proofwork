# Specification: option-arena

Trigger: consequential implementation uncertainty warrants bounded competing artifacts. Inputs: fixed brief, base
artifact, incumbent, acceptance, workload, authority and budgets. Output: comparison, chosen slice, integrated identity,
fresh checks, costs and gaps. Default two candidates; a configured third needs a distinct hypothesis. Honor actual host
limits and report unknown model/accounting observations.

Acceptance: mechanical work skips competition; candidates receive identical starting inputs in isolated workspaces;
failed contracts eliminate candidates; a combined patch gets new acceptance and regression checks; exhausted budgets
stop scheduling; unrelated changes survive integration. Reuse explore-options and model-patterns contracts.
