# Specification: thermo-nuclear-code-quality-review

Purpose: strict structural maintainability review rewards simpler models and earned interfaces without manufacturing criticism.

Inputs: authorized review scope/base, changed artifact, callers/contracts/tests, base/current line counts and applicable language guidance.

Workflow: establish scope; inspect ownership, state, abstractions and effects; measure growth; demonstrate feasible simplification and preservation constraints; issue findings and verdict; review authorized revisions.

Output/evidence: high-conviction located findings with mechanism/remedy/behavior constraints; exactly meets the bar, needs restructuring or insufficient evidence; executed checks and gaps.

Boundaries: review is read-only by default; no arbitrary splitting, cosmetic quotas, unchecked guard deletion, unrelated redesign or implied correctness/security certification.

Behavioral acceptance: pressure case 3 explicitly applies the below/above 1,000-line presumption with a structural exception or remedy; a clean case earns meets the bar; missing evaluation context earns insufficient evidence; passing tests never erase structural review.

Original authorship: existing user skill was inspected as a requirements reference only. This document and shipped instruction were independently authored to Proofwork's specification, not imported or mechanically paraphrased. Fresh baseline evals/results/baseline.txt respects review-only scope but lacks explicit threshold presumption and fixed verdicts. Post-skill observations are recorded by coordinator.
